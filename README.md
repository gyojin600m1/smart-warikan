# スマート割り勘

飲み会・旅行の会計をその場で計算して、そのままLINEに貼れる割り勘ツールです。

**公開ページ → https://gyojin600m1.github.io/smart-warikan/**

## 3つのモード

| タブ | できること |
|---|---|
| **かんたん均等** | 総額と人数から1人あたりを計算。100円/500円/1,000円単位で丸め、余った端数を幹事が被るか・幹事を安くするかを選べる |
| **傾斜割り勘** | 「上司は多め・後輩は少なめ」「飲む人と飲まない人」などをグループごとの比率（0.3〜2.5倍）で配分 |
| **立替・精算** | 誰がいくら立て替えたかを記録すると、**最も少ない送金回数**で全員の貸し借りが消える送金プランを出す |

どのモードも結果をLINE用のテキストにしてワンタップでコピーできます。

## つくり

- 単一HTML・外部ライブラリなし。ダブルクリックでも（`file://` でも）そのまま動きます
- スマホ優先。320px幅でも横スクロールしません
- 入力データはどこにも送信しません（計算はすべて端末内）

## 精算ロジックについて

「立替・精算」は各メンバーの純額（支払った額 − 負担すべき額）を出し、
債権者と債務者を金額の大きい順に突き合わせて相殺していきます（貪欲法）。

1円未満の端数は各人を個別に丸めると合計がずれて金額が消えるため、
残差を最大の債権者に寄せて **純額の合計が必ず0になる** ようにしています。
ランダムな2,000通りの立替パターンで、送金後に全員の残高が0になることを確認済みです。
